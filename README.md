# VELTRIX

A responsive Next.js frontend demonstration for the VELTRIX digital asset platform concept.

## Run locally

1. Install Node.js LTS from https://nodejs.org/
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Visit http://localhost:3000

## Deploy

Import this repository into Vercel and use the default Next.js settings.

## Important

This is a frontend demo only. It has no backend, authentication, database, wallet connection, deposits, withdrawals, custody, blockchain integration, or real investment products. All dashboard figures are illustrative placeholders. Do not accept real customer funds or represent demo figures as actual returns.
